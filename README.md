# AI Remote Finder

**「完全リモート」かつ「仕事内容の大部分をAI/RPAへ寄せやすい可能性が高い」Indeed求人候補だけを先に見る**ための、iPhoneホーム画面追加対応PWAです。

## 設計思想

単純なキーワード一致や1本のスコアだけではなく、候補を次の4軸で別々に判定します。

1. **AI代替性** — データ入力、転記、アノテーション、文字起こし、校正、分類、商品登録など、デジタルかつ定型化しやすいタスクの証拠
2. **完全リモート確度** — 「完全在宅」「フルリモート」等を強く評価し、出社・ハイブリッド・常駐を強く減点
3. **新しさ** — 公開検索インデックス側の日時と、複数回の再検出を利用
4. **人間依存リスク** — 営業、テレアポ、接客、訪問、対面、運転、介護等を除外

初期表示の **「高確度」** は4軸すべてに基準を設けています。どれか一つが弱い案件を、総合点だけで高確度に押し上げません。一方、情報不足で惜しい案件は **「要確認候補」** に残すので、厳しすぎて何も出ない問題も避けます。

## データ取得方針

- Indeed求人ページをbotで直接巡回・スクレイピングしません。
- 公開検索エンジンのRSSインデックスに現れたIndeed求人URL・タイトル・スニペットだけを候補化します。
- 以前の候補を延々保持せず、**その更新回で再び検索結果に現れた求人だけ**をフィードへ残します。
- 最終的な募集状態と仕事内容は、アプリからIndeedを開いて本人が確認します。
- 応募送信は自動化しません。

この設計は「古すぎる情報を減らす」と「候補ゼロになりすぎない」の両方を狙ったものです。ただし公開検索インデックスはIndeedのリアルタイム求人DBではないため、現在募集中であることを保証できません。

## 主な機能

- 高確度 / 要確認 / 全候補 / 保存済み の切替
- AI代替性・完全在宅確度・新しさを別表示
- 人間依存リスクの表示
- 総合順 / 新しい順 / AI代替順
- キーワード絞り込み
- iPhone内のお気に入り保存
- ワンタップでIndeed求人ページを開き確認・応募
- 条件付きIndeed検索へのショートカット
- 6時間ごとのGitHub Actions自動更新
- 検索取得の成功数を画面に表示
- 判定ロジックの回帰テスト

## GitHub Pagesで使う

1. `Settings > Pages > Build and deployment > Source` を **GitHub Actions** にする。
2. `Actions > Update job candidates > Run workflow` を一度実行する。
3. Pages URLをiPhone Safariで開く。
4. 共有メニューから **ホーム画面に追加**。

以後は約6時間ごとに候補が更新されます。

## 「AI代替」の意味

このアプリが判定するのは **技術的なタスク代替のしやすさ** です。雇用主がAI利用を許可していること、守秘義務上入力可能であること、成果物の自動生成が契約上認められることまでは判定できません。応募後・就業前に必ず会社のルールを確認してください。

## ファイル

- `scripts/fetch_jobs.py` — 公開検索インデックス取得、鮮度管理、4軸スコアリング
- `data/jobs.json` — 現在候補だけのフィード
- `index.html`, `app.js`, `sw.js` — PWA UI
- `tests/test_scoring.py` — 高確度判定の安全網
- `.github/workflows/update-jobs.yml` — 定期更新
- `.github/workflows/pages.yml` — Pages配信
